# ChromeAlwaysOnTop

키오스크 PC에서 Chrome 창이 항상 다른 창보다 위에 표시되도록 유지하는 작은 Windows 프로그램입니다.

실행하면 화면에 아무것도 띄우지 않고 백그라운드에서 동작합니다. 정해진 주기마다 `chrome.exe`의 창을 모두 검사해서, 아직 항상 위(topmost)로 설정되지 않은 창이 있으면 항상 위로 설정합니다.

> [!WARNING]
> 이 프로그램은 키오스크 전용으로 만들었습니다. 일반 업무용 PC에서 실행하면 Chrome 창이 다른 모든 프로그램을 가리게 되고, 로그인할 때마다 자동으로 다시 실행됩니다.

## 특징

- 설치 과정이 없고, 별도의 런타임도 필요하지 않습니다. C 런타임은 실행 파일 안에 정적으로 포함되며, 나머지는 Windows에 기본으로 들어 있는 DLL만 사용합니다.
- 실행 파일의 크기는 13KB 정도입니다.
- 창, 트레이 아이콘, 콘솔을 띄우지 않습니다.
- 실행하는 즉시 로그인할 때 자동으로 실행되도록 등록됩니다.
- 이미 항상 위로 설정된 창은 건너뛰므로, 주기를 짧게 잡아도 CPU를 거의 사용하지 않습니다.

## 요구 사항

- Windows 11 x64
- ARM64 기반 Windows 11에서는 x64 에뮬레이션으로 실행됩니다.

## 사용법

`ChromeAlwaysOnTop.exe`를 키오스크 PC의 고정된 위치에 복사한 다음 실행합니다.

| 명령 | 동작 |
| --- | --- |
| `ChromeAlwaysOnTop.exe` | 1초마다 검사합니다. |
| `ChromeAlwaysOnTop.exe 500` | 500밀리초마다 검사합니다. |
| 실행 중에 한 번 더 실행 | 실행 중인 인스턴스를 종료합니다. |

검사 주기는 밀리초 단위로 지정하며, 100부터 3600000(1시간)까지 쓸 수 있습니다. 이 범위를 벗어난 값은 가장 가까운 경계값으로 바뀝니다. 인수를 생략하거나 0 또는 숫자가 아닌 값을 넣으면 1초 주기로 동작합니다.

한 번에 하나의 인스턴스만 실행됩니다. 프로그램을 종료해도 이미 항상 위로 설정된 Chrome 창은 그 상태를 유지합니다. 원래 상태로 되돌리려면 Chrome을 다시 시작합니다.

## 자동 실행

프로그램은 실행될 때마다 다음 위치에 자신을 등록합니다. 현재 사용자 영역에 기록하므로 관리자 권한이 필요하지 않습니다.

```
HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run
값 이름: ChromeAlwaysOnTop
```

- 실행할 때 지정한 검사 주기도 함께 기록되므로, 로그인할 때도 같은 주기로 실행됩니다.
- 실행 파일을 다른 위치로 옮긴 경우에는 새 위치에서 한 번 실행하면 등록된 경로가 갱신됩니다.
- 실행 중인 인스턴스를 종료해도 등록은 해제되지 않습니다.

자동 실행을 중지하려면 작업 관리자의 **시작 앱** 탭이나 **설정 > 앱 > 시작 프로그램**에서 `ChromeAlwaysOnTop`을 끕니다. 이렇게 끈 설정은 프로그램을 다시 실행해도 유지됩니다. 등록 자체를 삭제하려면 다음 명령을 실행합니다.

```cmd
reg delete "HKCU\Software\Microsoft\Windows\CurrentVersion\Run" /v ChromeAlwaysOnTop /f
```

## 동작 방식

1. 이름 있는 이벤트 객체를 만들어서 다른 인스턴스가 실행 중인지 확인합니다. 이미 실행 중이면 그 인스턴스에 종료 신호를 보내고 곧바로 끝납니다.
2. 자동 실행 항목을 등록합니다.
3. 최상위 창을 모두 열거해서, 화면에 보이면서 아직 항상 위가 아닌 창을 고릅니다.
4. 고른 창을 소유한 프로세스의 실행 파일 이름이 `chrome.exe`인지 대소문자를 구분하지 않고 확인합니다. 같은 창 클래스를 쓰는 Edge, Visual Studio Code 같은 프로그램은 이 단계에서 제외됩니다.
5. 조건에 맞는 창을 포커스를 빼앗지 않는 방식으로 항상 위로 설정합니다. 응답하지 않는 창 때문에 검사가 멈추지 않도록 비동기로 요청합니다.
6. 화면에 보이지 않는 메시지 창의 타이머로 지정한 주기마다 3단계부터 반복합니다. 종료 신호를 받으면 이 창을 닫아 프로그램을 끝냅니다.

## 제한 사항

- 실행 파일 이름이 정확히 `chrome.exe`인 프로세스만 대상으로 합니다. Chrome에서 설치한 웹 앱(PWA)도 `chrome.exe`로 실행되므로 함께 대상이 됩니다.
- 팝업과 보조 창을 포함해서 화면에 보이는 Chrome 창을 모두 항상 위로 설정합니다. Chrome 창끼리는 일반 창처럼 서로 앞뒤 순서가 바뀝니다.
- 이미 항상 위로 설정된 창은 다시 올리지 않습니다. 따라서 다른 프로그램의 항상 위 창이 나중에 나타나면 그 창이 Chrome 창보다 위에 놓일 수 있습니다.
- Chrome을 관리자 권한으로 실행했다면, 이 프로그램도 관리자 권한으로 실행해야 Chrome 창을 변경할 수 있습니다.
- 실행 파일에 코드 서명이 없습니다. 그래서 Windows Defender 같은 백신이 작은 실행 파일을 악성으로 잘못 판단할 수 있습니다. 브라우저에서 내려받은 파일이라면 차단되거나 격리될 수 있으며, 이 경우 파일을 직접 복사해서 쓰거나 백신 예외로 등록해야 합니다.

## 빌드

다음 도구가 필요합니다.

- Visual Studio 또는 Build Tools의 **C++를 사용한 데스크톱 개발** 워크로드 (MSVC 컴파일러와 Windows SDK)

저장소 폴더에서 `build.cmd`를 실행하면 `bin\ChromeAlwaysOnTop.exe`가 만들어집니다. 스크립트가 `%ProgramFiles%`와 `%ProgramFiles(x86)%`에서 설치된 Visual Studio를 찾아 빌드 환경을 스스로 구성합니다.

표준 MSVC 컴파일러와 링커로 빌드하고 C 런타임을 실행 파일 안에 포함하므로, 재배포 패키지를 따로 설치할 필요가 없습니다. 버전 정보는 `src/app.rc`에 들어 있습니다.
